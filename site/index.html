SPOTLED EDITOR

A browser-based editor for SpotLED 48×12 LED boards. Draw animations of up to 20 frames pixel by pixel, type scrolling text with built-in or custom fonts (e.g. Amstrad CPC), import PNG images, or start from the gallery of ready-made animations. Projects are saved as JSON files that are compatible with the Android app. When you are done, send the animation straight to the board over Bluetooth LE – no installation needed, just Chrome, Chromium or Edge.

Prefer a native app? Download the Android version from the latest release. More information can be found in the README on GitHub – see the project home page.

Unofficial hobby project, not affiliated with the manufacturer of the SpotLED device. Use at your own risk.
